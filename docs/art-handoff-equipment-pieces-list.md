Generated by `python3 tools/equipment_pieces.py list` from the same data as [`art/equipment/handoff-pieces.json`](../art/equipment/handoff-pieces.json), which has each file's full prompts, references and masks. How to make them is in [art-handoff-equipment-pieces.md](art-handoff-equipment-pieces.md). Run `list` again after delivering to tick off what's in (a file is ticked when it's there and passes `check`).

**Pri** is the batch (1 first). A piece's file is `pieces/<base>/<family>.png`: the family's pieces that show on that base (its picture to paint on is `art/equipment/inputs/bases/<base>.png`), and **Pieces** counts them. ★ marks a family's first file, which sets its design: make it first, then pass it as a reference picture for the family's other files ("as #n"). ↻ marks the plates painted on a seeded base (the plate with the family's whole-figure picture on it; `inputs` makes it).
